## 发现及 0.2.3 修复

1. 原始日志每行递增版本，城镇台词和 `ctrlprobe: cursor fight` 使无状态变化的动作被拒绝。保留原始游标，仅允许连续、完整、最多 2,000 行且全部为明确白名单中的未解析台词、光标冲突诊断、语音后端回执的增量通过。状态事件、未知日志、缺失历史、文件代际间隙和未来版本一律拒绝。核对使用更新后的状态，执行与不确定动作去重保持原有语义。
2. 人物档案 `charsheet`、饰品箱 `realminv` 遮挡出征界面，但仍返回出征选项。现在将它们归为 modal，背景快照不会覆盖此阶段，底层操作在发送前拒绝。只提供关闭操作；关闭仍须观测到界面实际离开，不能把按下 Esc 视为关闭成功。
3. 重新检查准备信息会在 delta 中重复输出所有任务文本。任务说明统一保留在当前 decision 的任务选项中，文本更新仍即时呈现，full 模式保留原始记录。
4. 建筑候选列表可能在锁定槽中显示资格或零费用。紧凑输出排除锁定、活动锁定和不存在槽位的候选，完整原始信息仍可诊断。
5. 雷蒙德、瘟疫医生及另一名强盗在城镇读取到 `1/max`。人物档案界面仅展示最大生命，不能据此确认当前生命。准备阶段明确标记这种读数需要核对，不改写为满血，也不自动认定濒死。
